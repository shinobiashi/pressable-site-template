## 指摘
### [R2-1][High][.claude/skills/rename-site/scripts/rename.py（token_rules）]
R1-2 の修正（直後が `_` なら PHP 接頭辞と判定）により、`.phpcs.xml.dist` の PrefixAllGlobals の `<element value="shop"/>`（末尾に `_` が付かない）がハイフンの形 `acme-theme` に置き換わる。PHPCS が「無効な接頭辞」と関数の接頭辞なしで 7 errors を出し、CI も落ちる。テストは `.phpcs.xml.dist` を見ていなかった。
**修正方針:** `.phpcs.xml.dist` の prefixes のブロックだけ、要素をアンダースコアの形に直す規則を line_rules に足し、`test_generic_slug…` で PHPCS の要素を確認する。
**対応:** 修正済み。ハイフン無しのスラッグを経由する 2 段階のリネーム後に PHPCS がエラー 0 になることを実測。修正を外すとテストが落ちることもミューテーションで確認。
